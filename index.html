FAQ

        
Pertanyaan yang Sering Diajukan

      

      

        

          
Bagaimana cara kerja SIPGN Autofill Script?

          
Skrip ini berjalan di browser melalui extension userscript (seperti Tampermonkey) untuk mengisi data secara otomatis sesuai template dan database KPM yang tersimpan.

        

        

          
Bagaimana cara memperpanjang lisensi klien?

          
Admin dapat masuk ke dashboard, memilih menu Client Devices, lalu menambahkan durasi hari atau membuat voucher khusus untuk device ID tersebut.

        

        

          
Apakah data backup KPM aman?

          
Ya, data backup KPM disimpan secara aman di server dengan sistem otomatisasi pembersihan (auto-purge) demi menjaga privasi dan performa.
